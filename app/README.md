# Tillstone app

The Flutter app for every platform and device role. All business logic lives in the Rust crates under `../crates`; this app only draws the UI, using `../packages/design_system`.

- `lib/src/rust/` is generated by flutter_rust_bridge. Regenerate with `flutter_rust_bridge_codegen generate` after changing `../crates/pos-core-ffi/src/api`.
- `rust_builder/` builds the Rust library for each platform (cargokit).
- `integration_test/proof_test.dart` is the M0 proof; see `../docs/m0-proofs.md`.
